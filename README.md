<sub>Next.js · TypeScript · FastAPI · PostgreSQL / pgvector</sub>

### [OpenSynapse](https://github.com/JesstLe/OpenSynapse)

将 AI 对话、笔记提炼、间隔重复复习与知识图谱连接起来，支持自托管与多设备访问。

<sub>React · TypeScript · PostgreSQL · Chroma · D3.js</sub>

### [NaumiAgent](https://github.com/JesstLe/NaumiAgent)

本地 Agent 系统：工具执行、多模型路由、会话恢复与长期记忆。

<sub>C# / ASP.NET Core · React · TypeScript · PostgreSQL</sub>
