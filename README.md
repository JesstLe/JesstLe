## 代表项目

### [OpenKnowledge](https://github.com/JesstLe/OpenKnowledge) · 本地知识管理

通过文档导入、RAG 问答与语义搜索，把本地资料转化为可检索、可对话的知识库；支持多种模型提供商。

<sub>Next.js · TypeScript · FastAPI · PostgreSQL / pgvector</sub>

### [OpenSynapse](https://github.com/JesstLe/OpenSynapse) · AI 学习与知识连接

将 AI 对话、笔记提炼、间隔重复复习与知识图谱串联起来，支持自托管与多设备访问。

<sub>React · TypeScript · PostgreSQL · Chroma · D3.js</sub>

### [门店 ERP](https://github.com/JesstLe/erp) · 连锁门店经营管理

围绕预约接待、会员、收银、库存和经营分析组织业务流程，支持品牌内多门店共享、品牌间数据隔离与操作审计。

<sub>C# / ASP.NET Core · React · TypeScript · PostgreSQL</sub>

### [NaumiAgent](https://github.com/JesstLe/NaumiAgent) · 本地 Agent

面向阅读、执行、记忆与协作的本地 Agent 系统，提供终端交互、工具执行、多模型路由与会话恢复。

<sub>Python · Node.js · SQLite · Chroma · LiteLLM</sub>
